# Apoia+ / The interface behind the support

**Frontend case study · React · TypeScript**

AI can support learning only if people can reach it through a clear, reliable interface. Apoia+ is a team-built platform for educational support with AI-assisted experiences. My work was on the frontend: making that experience usable across screens and easier to deliver.

## What I built and improved

- Refined responsive layouts and key journeys for mobile and desktop.
- Reduced route payload and repeated data requests.
- Improved accessibility and tightened frontend security behavior.
- Prepared API integration boundaries and a Docker Compose setup for a more repeatable handoff.

## The engineering behind it

React, TypeScript, Vite and Tailwind CSS form the interface. Tests, CI and Docker support the delivery workflow. The AI functionality belongs to the wider Apoia+ platform; this case study focuses on the frontend work I contributed.

## Source and availability

This repository is a written case study, not a runnable copy of the application. The frontend source is private in the ApoiaMaisTech organization. This page shares the scope of my contribution without exposing the code.
